## 功能特性

- **真实地图模式**：基于 Web 墨卡托瓦片，支持 OpenStreetMap 栅格底图与 Esri 卫星影像，可搜索并定位城市。
- **示意图模式**：一键将真实走向转换为八向（octilinear）折线示意图，支持自动布局、一键拉直、重置为真实走向。
- **站点与线路编辑**：
  - 普通站 / 换乘站；站点支持中文、英文、第三语言名称，字体、字号、颜色、加粗、描边可独立定制。
  - 线路支持主线与支线，线段类型（地下实线 / 切换点线 / 地上虚线）。
  - 锚点绕行与**钢笔式贝塞尔曲线锚点**（带双向手柄，平滑/尖角）。
  - 线路颜色、粗细、Logo 文字/图片、共线并置。
  - 两站间插入站点、断开为两条线路、合并线路。
- **样式与排版**：
  - 站名防遮挡：发生遮挡时自动翻转到线路另一侧，文字位置固定不漂移。
  - 东西向线路站名自动置于站点上方，避免压线。
  - 按拼音 / 名称 / 创建时间排序。
- **撤销 / 重做**，自动保存，最近项目列表，示例数据。
- **导出**（见下方）。

## 导出

支持多种格式，可在导出面板中调整尺寸、缩放倍率、内容开关与文字/线宽缩放：

| 格式 | 说明 |
| --- | --- |
| 线路图 SVG（不含底图） | 纯矢量线路图 |
| 线路图 SVG（嵌入底图） | 内嵌地图底图的线路图 |
| 示意图 SVG | 示意图模式的矢量图 |
| 示意图 PNG | 示意图位图，支持缩放倍率与 4× 高清分辨率 |
| PNG 图片 | 真实走向图位图，支持缩放倍率与 4× 高清分辨率 |
| PSD 分层文件（分组导入） | 按「文字 / 站点 / 线路 / 背景」分组，可导入 Photoshop |
| GeoJSON | 线路与站点的地理数据 |

## 快速开始

### 直接运行（发布版）

1. 从 [Releases](../../releases) 下载 `MetroPlanner-win-x64.zip` 并解压。
2. 确保已安装 [.NET 9 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/9.0)（Windows）。
3. 双击 `MetroPlanner.exe` 运行。

### 从源码构建

```bash
# 要求：.NET 9 SDK（Windows）
dotnet build -c Release

# 发布（framework-dependent）
dotnet publish -c Release -r win-x64 --self-contained false -o publish
```

## Metro Planner (English)

A desktop tool for **fictional metro line planning and visualization**, built with WPF / .NET 9.

> **AI disclosure**: The codebase is primarily generated by AI; a human provided the overall framework, feature requirements, and design direction.

### Highlights

- Real-map mode (Web Mercator tiles; OpenStreetMap + Esri satellite basemaps) and schematic mode (octilinear auto-layout).
- Full station/line editing: transfer stations, branches, anchor bypass, pen-style Bézier curve anchors, line styles, logos.
- Collision-free station labels that flip to the opposite side when overlapping.
- Export to SVG / PNG (with zoom factor & 4× resolution) / layered PSD (grouped import) / GeoJSON.

### Run

1. Download `MetroPlanner-win-x64.zip` from [Releases](../../releases) and unzip.
2. Install [.NET 9 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/9.0).
3. Run `MetroPlanner.exe`.

### Build

```bash
dotnet build -c Release
```
